# Social Media Usage Dashboard (Looker Studio)

## Project Overview

This project analyzes social media usage behavior using an interactive dashboard built in Google Looker Studio.

## Objectives

- Analyze screen time patterns
- Identify the most used social media platforms
- Study addiction levels
- Evaluate productivity loss
- Compare usage across demographic groups

## Tools Used

- Google Looker Studio
- Google Sheets / CSV
- Data Visualization

## Dashboard Highlights

- KPI Cards
- Interactive Filters
- Pie Charts
- Bar Charts
- Geographic Map
- Funnel Chart

## Key Insights

- Habit is the main reason for social media use.
- Instagram and YouTube are the most frequently used platforms.
- Strong addiction is associated with greater productivity loss.
